# Figure-level source data

Main-figure subfolders contain the exact tables used by the corresponding plotting source. Original full-precision numerical fields and separate cohorts are preserved. Local file-path metadata, if present in source tables, is reduced to a source basename; numerical cells are unchanged.

Important distinctions: Figure 1 phase-minus-neutral differences (pp) and event anomalies (%) have different references; Figure 3 shares (%), share changes (pp), signed weather components (pp) and observed yield contrasts are separate objects; Figure 5 combines yield at fixed area, area plus interaction and reported production under a common accounting reference; Figure 6 uses trend-referenced severe-low-yield probabilities and allocation bounds, distinct from historical MA5 anomalies.

The [figure/table index](../docs/figure_and_table_index.md) preserves the public numbering. The 25 events are shared physical ENSO events, not independent replicates for each country record. Full result-table companions provide additional support, qualifications and sensitivity columns.
