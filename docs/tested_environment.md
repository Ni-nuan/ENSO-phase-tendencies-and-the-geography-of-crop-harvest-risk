- pandas: 3.0.5
- matplotlib: 3.11.1
- geopandas: 1.1.4
- Pillow: 11.3.0
- PyMuPDF: 2.1
- scipy: 1.18.0
- scikit-learn: 1.9.0
- pyarrow: 23.0.1
- netCDF4: 1.7.4
- shap: not installed in the figure-test environment; required only for the optional model explanation functions
